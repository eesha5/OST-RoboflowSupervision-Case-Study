## Purpose

Supervision provides reusable tools for computer-vision applications.
It helps developers work with detection results, annotate images
and video frames, use zones, and manage datasets.

## Problem Addressed

Computer-vision applications often require repeated code for storing
bounding boxes, filtering detections, drawing labels, and handling
datasets. Supervision provides shared tools for these tasks.

## Intended Users

Potential users include computer-vision developers, researchers,
students, and engineers building image or video processing applications.

## Reason for Selection

The project provides Python source code, documentation, examples,
tests, and public development history. These resources support
investigation of both its functionality and its open-source workflow.

## Member 1 Practical Work
